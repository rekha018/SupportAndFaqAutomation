# Wire Support and FAQ

Automation tests for Wire support and FAQ page.

## Test Scenarios

1. Verify that main elements on Support and FAQ page are displayed

2. Search results displayed should be relevant to search keyword

3. Verify search functionality for no results

## Prerequisites

* Eclipse IDE
* Selenium WebDriver
* Chrome browser and chrome driver


## Tech/framework used

* Java
* Cucumber
* Maven
